# C4 D5 — learnable graph attachment: experimental proof and limits

Date 2026-10-09 | C4 project distinct from Singularity OS | Research, NOT canonical runtime

## The answer

**The fixed D3 'holder must precede operator' constraint is removable via trained graph-edge attachment, not via literal Russian if-conditions.** A small typed graph-edge scorer, trained on 288 teacher-labelled synthetic episodes, chose the attachment of unary operators, holders, and negation from span features. L2 logistic edge scores were learned externally (scikit-learn), then persisted as 181 `D5_GRAPH_EDGE_WEIGHT` facts in a COPY of actual C4 native `C4Graph`; the existing D3 token-tagging algorithm was trained on the same 288 lessons and saved as 687 more graph facts. Native inference uses a pure-Python `c4child/d5_graph_attachment.py` reader and the original D3 tag decoder, NO scikit-learn at inference.

The old D3 hardcoded AST constructor scores **0/32** on a prior independent saved reversed-role test EVEN WITH perfect tags; this new learned attachment scores **32/32** with gold tags, **21/32** with learned tags. Two-level reversed syntax with new entities: **100/100** gold tags, **63/100** native learned tags. Three-level reversed: **87/100** vs **50/100**. Three-level forward: **74/100** vs **5/100**. This measures the boundary: learned attachment is possible; fragile learned recognition remains.

This is NOT a proof that graph topology is learned from arbitrary examples. Structural ontology and the allowed chain-shaped AST, a single property proposition, type families `BELIEF/SAY/NOT`, max 5 operators, and Hungarian/permutation constrained search are coded **as general structural inductive bias**. This cannot parse conjunction, arbitrary branching, questions, temporal logic, reference or general natural language. No phrase-specific Russian routing was used in inference. An ablation removing learned HOLDER scores left synthetic scores unchanged: the data generator keeps holder/operator order aligned, so **learning of crossing holder bindings was NOT demonstrated**.

## Precise verdict / action

1. **NO-GO on C4 as current LLM replacement.** Free-text grounding, generalized topology, lexical grammar, learned natural speech generation, multi-turn independent human dialogue and stable continual learning not demonstrated. Previous full D2 RED.
2. **PARTIAL GO on a research branch:** expand the *learnable language transducer*, not constitutional owners or core graph. Train an end-to-end typed relation graph with variable binding, branching, source/scope, source contrast, and learnable utterance realization; strong negative/OOD calibration and multi-seed training. Crucial prove it on independently authored, syntactically disjoint natural conversations. Don't insert per-example if-handlers or a hidden Qwen responder.
3. **Today, use existing C4 in its evidenced role:** typed provenance-preserving memory, structured interpretation and action gate in another project if desired (without conflating architectures). Do not rely on C4 as the conversational voice.
4. **Qwen-Omni teacher** mass synthesis remains blocked. If next gates pass, Qwen may provide dependent synthetic lessons and audio groundings, never outcomes verification, nor be the responder during C4 evaluation.

## Reproduce

Archive contains original model, new trained model, full 60-ish Python-module research runtime under `native_runtime/c4child`, all source scripts, frozen datasets, results, logs, SHA256 manifest. Scripts were run from `/mnt/data/c4_d5_graph_lab` with previous D3/P2C reference directories as named in code; to reproduce out of archive, update the local fixture paths to where you extract the bundled previous assets, keeping hashes exactly as in this manifest. Python requirements: Python 3.11+, numpy/scikit-learn for training only, pytest for tests; pure-Python native model inference.

Primary scripts: `experiment.py` (structured perceptron capacity), `logistic.py` (L2 pairwise logistic learning), `persist.py` (BootstrapTeacher strict graph weight storage; cold reload), `reattack.py` (negative controls), `final_native.py` (manual natural reattack), `test_d5.py` (native regression). Binary `C4_D5_LEARNED_EDGE_RESEARCH_ONLY.c4m` has NOT been promoted to main C4, and runtime zip has NOT been proven on Android.
