# C4 G331 — исправление действующего организма G329, НЕ второй рантайм

**Внимание**: экспериментальная ветка. Создайте копию своего `.c4m` перед заменой runtime ZIP. G309 остаётся последней канонической линией. G329 `.c4m` полностью совместим, никакого нового организма/памяти/весов нет.

## Что ставить на телефоне

1. В уже установленном C4 Nursery: остановить организм и сохранить резервную копию файла `.c4m`.
2. **Система → Импорт runtime ZIP**: выбрать `C4_G331_NATIVE_COGNITION_RUNTIME.zip`.
3. В **Организм** выбрать **свой существующий `.c4m`**, как и раньше, запустить C4.
4. В чате вводить **одну строку `@c4 {...}` в одно сообщение** (примеры ниже). Простые русские фразы продолжают идти в старый речевой тракт G329; псевдоязык включает только структурный когнитивный вход.
5. В разделе логов включить **C4 Trace Recorder → Next interaction / DEEP**. Экспортировать чат + логи, а не только скриншоты.
6. При любых сбоях импортировать назад исходный G329 runtime ZIP и открыть резервную копию `.c4m`.

## Для чего нужен псевдоязык

Не запоминает русский язык и не подменяет мозг. Он сообщает EVAL **тип происходящего** напрямую, чтобы проверить уже существующие граф, событийную память и DRIVE. Слова `lamp`, `Ivan`, `LIGHT` — произвольные символы, а не ответы в коде. Значение переменной задаётся связями и последствиями.

### Отправляй по одной строке в чат

```text
@c4 {"op":"SOCIAL","act":"PRAISE"}
@c4 {"op":"SOCIAL","act":"ACCEPT_THANKS"}
@c4 {"op":"TOPIC","subject":"moss"}
@c4 {"op":"REPORT","scope":"STORY","scene":"story1","frames":[{"actor":"Masha","mode":"BELIEF"},{"actor":"Ivan","mode":"QUOTE"}],"fact":{"subject":"Ivan","relation":"LOCATION","object":"home"}}
@c4 {"op":"QUERY","scope":"STORY","scene":"story1","frames":[{"actor":"Masha","mode":"BELIEF"},{"actor":"Ivan","mode":"QUOTE"}],"fact":{"subject":"Ivan","relation":"LOCATION","object":"?"}}
@c4 {"op":"QUERY","scope":"SOURCE","scene":"story1","fact":{"subject":"Ivan","relation":"LOCATION","object":"?"}}
@c4 {"op":"REPORT","scope":"SOURCE","scene":"talk","fact":{"subject":"moon","relation":"MATERIAL","object":"cheese"}}
@c4 {"op":"REPORT","scope":"SOURCE","scene":"talk","fact":{"subject":"moon","relation":"MATERIAL","object":"rock"}}
@c4 {"op":"QUERY","scope":"SOURCE","scene":"talk","fact":{"subject":"moon","relation":"MATERIAL","object":"?"}}
@c4 {"op":"GOAL","scope":"SIM","scene":"room","target":{"subject":"lamp","relation":"LIGHT","object":"ON"}}
@c4 {"op":"DEMO","scope":"SIM","scene":"room","action":"press","before":{"subject":"old_lamp","relation":"LIGHT","object":"OFF"},"after":{"subject":"old_lamp","relation":"LIGHT","object":"ON"}}
@c4 {"op":"PLAN","scope":"SIM","scene":"room"}
@c4 {"op":"REFLECT","scope":"SIM","scene":"room"}
@c4 {"op":"REPORT","scope":"WORLD","fact":{"subject":"moon","relation":"MATERIAL","object":"cheese"}}
```

Последняя строка — намеренная атакующая проверка: должна быть **отклонена без изменения графа и без остановки приложения**.

**Не надо** загружать `C4 LIFE v1` или новый `.c4m`. Эти команды предназначены только G331 runtime ZIP из этого пакета. Это всё ещё эксперимент, а не полнофункциональный интеллект.

## Что именно теперь исполняется (а не описывается)

- Вход поступает в `C4LivingRuntime.user_message` и прежнюю `semantic_spine`/`life_events`, без нового сервера или памяти.
- REPORT формирует только `SOURCE_ASSERTED` в уже существующем `C4Graph`, по строгому `evaluate_mutation(STRICT, ...)`: не становится WORLD.
- Вложенные REPORT/BELIEF/QUOTE/IRONY сохраняют контекст и проверяются QUERY без переноса в другие миры.
- Социальное продолжение связывает текущую реплику с **конкретным прежним C4 REPLY**.
- Неизвестная тема создаёт gap в существующем G329 `KnowledgeGapRegistry`, и прежний DRIVE может самостоятельно сформулировать вопрос после нескольких `TICK`.
- SIM GOAL/DEMO/PLAN: кандидатная процедурная стратегия переносится на иной объект по структуре отношения и следствия, но собственное предложение не считается исполнением.
- Настоящий штраф/награда стратегии возможен ТОЛЬКО после подтверждённого **host SIM callback**; Android UI пока не связывает эту экспериментальную функцию с физикой комнаты. На телефоне это будет *предложение*, не выполненное действие. На Python в тестах обратная связь через хост меняет выбор стратегии. **Нельзя подделать результат фразой в чате.**
- Все переходы видны через имеющийся TRACE, а цели/процедурные кандидаты живут в `runtime_state.cognitive_g331`, который сериализуется прежним `.c4m`. Ни одной новой базы фактов.

## Доказательства / ограничения

- Из исходного G329 runtime ZIP взяты все 55 `.py` файлов; изменён только `c4child/runtime.py`, добавлен `c4child/structured_cognition.py`.
- 23/23 новых теста, 73/73 направленных старых теста; доступный расширенный набор: 559 PASS / 27 FAIL, все 27 из-за отсутствующих архивов прежних поколений. **Это не тот же набор, что был 715 PASS в исходном выпуске G329**.
- На **физическом G329 `.c4m`** с 10 781 фактами проведены загрузка → сообщение → сохранение → холодное открытие; утверждение сохраняется как `SOURCE_ASSERTED`.
- В этой ветке НЕ доказаны: произвольное понимание русского, независимое физическое подтверждение через Android, открытое рассуждение уровня человека, автономная перестройка собственных когнитивных операторов, безопасная изоляция Python-модулей. Не путать ранний экспериментальный орган с полной архитектурой C4.
