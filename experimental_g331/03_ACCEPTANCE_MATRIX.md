# C4 — матрица функциональной приёмки (не scoreboard)

**Цель:** реализовать задуманную обучаемую когницию C4 на реальном G329/G331 организме, без второго рантайма и потери памяти. Псевдоязык допустим до обучения свободному русскому, но не должен заранее подсказывать ответы и решения.

| Gate | Что нужно продемонстрировать на новом, не заложенном в код кейсе | Статус 2026-10-08 |
|---|---|---|
| A0 Compat | Тот же `C4LivingRuntime`, загрузка прежнего G329 `.c4m`, сохранение/перезагрузка без потерь; неизменный старый русский путь | Локально заявлено в G331 checkpoint; независимый LIVE ещё нет |
| A1 Lifeline | Многоходовый диалог с продолжением, сменой темы, социальными актами и привязкой к конкретным прошлым репликам | Часть в G331 типизированном входе; свободный диалог НЕ ДОКАЗАН |
| A2 Perspective | `я/ты/он`, цитата в цитате, убеждения, шутка/ирония, отделение чужих мыслей от фактов и собственных наблюдений | Частичная структурная реализация; unseen-composition НЕ ДОКАЗАН |
| A3 Time | Время события, получения сообщения, пересмотра знания, часы/временные выражения, «вчера сказал, что завтра» и cold reload | НЕ ЗАКРЫТО |
| A4 Causal | Контрфакты, составные цепи, разные SIM-миры, пересмотр объяснения после новых доказательств | Элементарные правила; общий перенос НЕ ДОКАЗАН |
| A5 Initiative | Вопрос/мысль без прямой команды, связывается с исходным пробелом, спрашивает подходящего собеседника, не навязывает повтор | Один ограниченный путь G329 gap→DRIVE→ASK; широкий экзамен НЕ ДОКАЗАН |
| A6 Outcomes | Намерение ≠ действие ≠ подтверждённое следствие, независимый Android receipt, отложенная обратная связь, причинное назначение награды/штрафа | Только локальный host-SIM путь; Android НЕ ЗАКРЫТО |
| A7 G215 | Источник не штрафуется за несогласие с собственным убеждением C4; поддержка независимых roots, опровержений и пересмотра собственных правил | Точечная защита G331; адаптивный/сквозной G215 НЕ ЗАКРЫТ |
| A8 Learning | Усвоение новых отношений/операторов на малых примерах, неожиданный перенос на незнакомые конструкции, конкурирующие стратегии, обратимость ошибки | НЕ ЗАКРЫТО |
| A9 Language | Части русского (звук/слова/предложения) композиционно переводятся в общий опыт, без шаблонов фраз; живой диалог в приложении | НЕ ЗАКРЫТО |
| A10 Device | Физический Android: native trace, корректный .c4m, сохранение, реальные сенсоры/действия и внешние квитанции | НЕ ПРОВЕРЕНО |

### Критерий подтверждения любого Gate
1. Frozen unseen-тест **до** исправления и ожидаемый RED с трассой.
2. Минимальный кодовый ремонт именно существующего организма, без специальных строк-вопросов и ответов.
3. Повторная атака на иной предмет/источник/время/перспективу.
4. Все доступные направленные старые тесты и общий прогон с отдельным числом отсутствующих фикстур.
5. `.c4m` snapshot → cold reload → повторение непротиворечивого поведения.
6. Для Android — реальный журнал устройства, иначе пометка NOT ATTESTED.
7. Только затем запись DONE в `01_WORK_JOURNAL.md` и физический checkpoint SHA.

**Принцип:** цель пользователя — когнитивный организм, который может самостоятельно приобретать новые способности, а не энциклопедия с корректной памятью. Большие PASS-счётчики не заменяют этот экзамен.
