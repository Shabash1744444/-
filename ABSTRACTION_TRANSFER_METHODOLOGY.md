# C4 ABSTRACTION TRANSFER METHODOLOGY

Normative from G255 onward.

## 1. Training carrier vs objective
Rich source material is a curriculum carrier.

CONTENT CARRIER != LEARNING OBJECTIVE
EXAMPLE != RULE
FREQUENT EXPOSURE != NORMATIVE ENDORSEMENT
CREATOR PREFERENCE != C4 PREFERENCE
AUTHOR VIEWPOINT != C4 VIEWPOINT
LYRICAL VIEWPOINT != C4 VIEWPOINT
TEACHER INTERPRETATION != REQUIRED PERSONAL TASTE

The goal is reusable cognitive structure.

## 2. Typed association graph
Treat association as typed, not generic.

Useful edge families include:
- co-occurrence
- temporal adjacency
- causal evidence
- analogy
- contrast
- symbolic mapping
- part-whole
- shared structure
- source/provenance
- recurrence
- transformation

ASSOCIATION != CAUSATION.
ANALOGY != IDENTITY.
TEMPORAL ADJACENCY != CAUSAL DEPENDENCE.
SYMBOLIC MAPPING != PHYSICAL EQUIVALENCE.
GRAPH PATH != PROOF.

## 3. Semantic depth
Keep layers separate:
DIRECT
PRAGMATIC
SYMBOLIC
ASSOCIATIVE
AFFECTIVE
PHILOSOPHICAL
EPISTEMIC
META

DEEPER != TRUER automatically.
Several readings may coexist.

## 4. Transfer
A useful abstraction transfers across unrelated surfaces.

Example:
one poem, one visual clip and one scientific model may all instantiate PART/WHOLE,
but this does not make the domains identical.

Transfer selected relations only.
Reject unmapped property leakage.

## 5. Mathematical framing
A concept network may be modeled as typed graph G=(V,E).
Similarity is graded and not identity.
P(interpretation|cues) can model support but not author-mind access.
Dependent cues must not masquerade as independent evidence.
Compression is useful only if relevant structure survives.

## 6. Part/whole and scale
PART != WHOLE.
Whole properties need not belong to every part.
Part properties need not characterize the whole.
Scale changes which description is useful.
Accumulated local change may yield large global effects.
Emergent pattern need not be explicitly represented by one component.

## 7. Identity and time
Persistence does not require all properties to remain fixed.
Same name != same state.
Classification change != physical transformation.
Repeated motif with variation may preserve pattern identity without byte identity.

## 8. Meaning/truth/value
MEANINGFUL != FACTUALLY TRUE
BEAUTIFUL != TRUE
EMOTIONALLY POWERFUL != EVIDENTIALLY STRONG
MORALLY VALUABLE != EMPIRICALLY VERIFIED
FICTIONAL INSIGHT != HISTORICAL EVIDENCE

## 9. Perspective and contradiction
Different viewpoints may select different aspects.
Genuine contradiction requires same relevant scope/time/meaning.
Ambivalence != logical contradiction automatically.
Apparent contradiction may dissolve after scope/time/reference separation.

## 10. Media form
Music, image, montage, syntax and rhythm can organize meaning without directly asserting propositions.

LOUDER != TRUER.
FASTER != MORE CORRECT.
DARKER IMAGE != OBJECTIVE SADNESS.
RECURRENCE != UNIVERSAL SYMBOL.
GENRE != COGNITIVE OBJECTIVE.

## 11. Causal restraint
Association can motivate causal investigation.
It cannot substitute for causal evidence.

CORRELATION != CAUSATION.
TEMPORAL ORDER alone != CAUSATION.
COMMON CAUSE can generate correlation.
Narrative coherence != causal correctness.

## 12. Generalization tests
Hide title/author/genre where possible.
Use unseen material.
Test whether previously learned abstract relations apply.
Do not count memorized source-specific associations as transfer.
Preserve UNKNOWN/ALTERNATIVES when cues are insufficient.

## 13. Current creator intent
Ruslan explicitly wants songs, literature and video used because they are dense association-rich material for teaching complex transferable structures.
Store this as CREATOR_REPORTED curriculum intent, not a universal fact.
