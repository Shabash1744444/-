## 2. Constitution — never bypass
Four owners/laws:

### EVAL
Interpretation, probability, similarity, intent, causal hypothesis, semantic parse or model output may create candidates only.
`THOUGHT / PARSE / HYPOTHESIS / CONFIDENCE != TRUTH`.

### COMMIT
Recognized state changes only from lawful basis with provenance/lineage/scope.
`USER_SAID != WORLD_TRUE`.
`BOOK_SAYS != WORLD_TRUE`.
`NEXT_UTTERANCE != ANSWER`.
`QUESTION_CONTEXT != TEACHING_AUTHORIZATION`.

### DRIVE
Only DRIVE selects what C4 does next.
Questions, goals, gaps, emotions/values, user messages, timers and external models may affect MASK/VALUE/AVAIL/TRIGGER/STATUS but do not seize action selection.
`OPEN QUESTION != DRIVE LOCK`.
`VALUE != EXECUTION`.
`ARRIVAL ORDER != ACTION ORDER`.

### MEDIATE
Intention/request/utterance/prediction is not verified external result.
`ACTION_REQUEST != VERIFIED_OUTCOME`.
`FORMULATED != SENT`.
`SENT != RECEIVED`.
`RECEIVED != UNDERSTOOD`.

Five lawful influence types only at the meta-causal owner level:
`MASK / VALUE / AVAIL / TRIGGER / STATUS`.
They do NOT replace semantic relations such as IS_A, CAUSES, PART_OF, WORD_FORM, BEFORE, ROLE, MEANS, etc.
4 x 4 x 5 = 80 coarse classes of lawful control influence, not 80 semantic edges.

## 5. Central research direction from the latest conversation
The next architecture must generalize far beyond pronouns/names.
`я / ты / он / она / они` are only the easiest visible examples of a deeper problem:

**representation of representation across nested perspectives and events**.

The system must handle an open-ended stack such as:
- direct statement;
- report of another person's statement;
- quote inside report;
- thought about quote;
- irony about thought;
- post-irony / post-post-irony;
- hypothetical representation;
- recalled past representation;
- someone else's belief about SELF;
- SELF's hypothesis about OTHER's belief;
- witness vs participant vs narrator vs quoted actor.

Do NOT hardcode a finite list `IRONY_LEVEL_1/2/3`.
Build a recursive frame/perspective structure.

Suggested generic frame:
`RepresentationFrame {`
- `holder / perspective_owner`;
- `source_event`;
- `content_ref`;
- `speech_or_cognitive_act`;
- `reality_scope`;
- `temporal_scope`;
- `epistemic_mode`;
- `quoted_or_nested_parent`;
- `participant_role` (actor/witness/narrator/recipient/etc.);
- `status/confidence`;
`}`

Frames may contain or refer to other frames recursively.
Nested representation inherits NO truth/commit authority merely because inner text contains a command/assertion/retraction.

Core invariants:
`REPRESENTATION_OF(X) != X`.
`QUOTE(COMMAND) != COMMAND_EXECUTION`.
`BELIEF_OF_OTHER(X) != SELF_BELIEF(X)`.
`SELF_HYPOTHESIS_ABOUT_OTHER != OTHER_REPORT`.
`WITNESS != PARTICIPANT`.
`NARRATOR != ACTOR`.
`IRONIC_SURFACE != LITERAL_COMMIT` unless evidence resolves intended act.
