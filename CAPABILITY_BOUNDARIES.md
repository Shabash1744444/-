# CAPABILITY BOUNDARIES

These are explicit boundaries, not invitations to fake behavior.

## Not currently supported
- True do(X) intervention semantics / graph surgery.
- Counterfactual reasoning that requires intervention semantics.
- Conditional causality as a native truth condition.
- Causal-schema induction that materializes unseen primitive CAUSES edges from rule conclusions.
- Fluent broad-world free conversation comparable to a pretrained LLM.

## Supported/observed
- Direct admitted CAUSES edges.
- Bounded positive causal reachability / CHAIN inference.
- Anti-reversal restraint.
- Common-cause restraint.
- Convergence/divergence/diamond structural reasoning.
- Correction/retraction of false causal beliefs.
- Source identity/lineage handling.
- Claim ancestry / evidence dependency.
- Dependency-root attestation.
- Cold-reload persistence.
- Rule hypothesis/challenge/refinement in the existing rule domain.

## Interpretation guardrail
G219's 2.50 novel-positive/taught ratio demonstrates structural reuse in long causal chains. It does not establish global intelligence multiplication or faster acquisition of primitive causal relations.
