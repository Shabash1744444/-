# C4 CARDINALITY / SCOPE NOTE

Current LOCATION, COLOR and VALUE use FUNCTIONAL storage semantics.
Do not interpret that as universal world-level single-valuedness.

Examples:
- an object may have several colors simultaneously;
- location may be hierarchical or time-scoped;
- generic VALUE needs a measured dimension/context.

FUNCTIONAL SLOT != UNIVERSALLY SINGLE-VALUED WORLD PROPERTY.
CARDINALITY != TEMPORAL SCOPE.
CARDINALITY != CONTEXT SCOPE.

Do not blindly flip these relations to SET. Resolve later with explicit scope/context design before multimodal perception.
