## The single tested candidate

A **typed, scoped, provenance-preserving causal factor / hyperconstraint graph** with one generic generalized-arc-consistency-and-bounded-evaluation algorithm. The candidate is a possible *organization layer*, not a fifth constitutional owner and not a collection of hard-coded user utterances. Factor tables are supplied by outside perceptual/learning systems; this P0 does **not** discover them from data.

The key ideas:

1. Every variable is indexed by exact typed identity, WORLD/SIMULATION/other scope, perspective frame and time. Accidental lexical equality cannot merge distinct claims.
2. N-ary factors can express genuine intersections that are invisible when processes are analyzed independently. Local propagation can resolve global constraints.
3. Input claims/evidence carry dependency roots; repeated reports with the same root are not counted as new independent corroboration.
4. EVAL inference emits candidates, ambiguity, inconsistency or budget exhaustion. It does **not** authorize COMMIT, select an action, or synthesize MEDIATE verification.
5. Unexpected candidate from overlapping legitimate constraints is **not** automatically a constitutional violation. Unauthorized graph mutation **is** a violation.

The real G322 integration in this experiment is deliberately narrow: a *generic quote-boundary quarantine* in `semantic_spine.py` prevents name extraction from inside quote text from being misattributed to the outer speaker. It does **not** implement general nested semantic understanding; G323 reports a separate recursive perspective workstream whose exact binary was not available when this copy was made.

6. Release only after genuine full regression, cold replays with exact binaries, transfer tasks and failure inventory.
