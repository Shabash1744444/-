# C4 LITERATURE TRAINING METHODOLOGY

This file is normative for the Dostoevsky/literature phase.

## 1. Source hierarchy
Keep these roles distinct:
AUTHOR
NARRATOR
CHARACTER
QUOTED CHARACTER
REPORTED SPEAKER
READER-AS-TEXTUAL-ADDRESSEE
CURRENT USER
TEACHER ANALYSIS
C4 SELF

Never collapse one role into another without explicit evidence.

AUTHOR != NARRATOR
NARRATOR != CHARACTER
CHARACTER != AUTHOR
READER IN TEXT != CURRENT USER automatically
SOURCE TEXT != TEACHER INTERPRETATION

## 2. Fiction boundary
A fictional event may be true inside the novel while having no external-world truth claim.

FICTIONAL_WORLD_FACT != EXTERNAL_WORLD_FACT

Do not use fiction as factual evidence about real people, history, psychology, religion or metaphysics unless separately sourced.

## 3. Dense literary cell
For high-value scenes or expressions, build as many useful typed projections as supported:

TEXT: literal wording/semantic core
SOURCE: book/chapter/speaker/provenance
SPEAKER: who says/thinks/reports
ADDRESSEE: intended receiver
NARRATIVE: narrator frame and viewpoint
TEMPORAL: event time vs narration/remembering time
SOCIAL: roles, status, relationship
PRAGMATIC: speech act, likely intent, face strategy
EMOTION: attributed state and evidence
ACTION: what physically/socially happens
LINGUISTIC: syntax, idiom, metaphor, polysemy, irony
PHILOSOPHICAL: abstract question or value conflict
EPISTEMIC: observation/report/inference/hearsay/uncertainty
ALTERNATIVES: competing readings
SELF-WORLD: safe transfer to C4 without absorbing character state

More layers are useful only when they remain typed and non-substitutable.

## 4. Human-state separation
Do not flatten a person into one statement or trait.

SELF_REPORT != ACTION
ACTION != DESIRE
DESIRE != VALUE
VALUE != COMMITMENT
COMMITMENT != VERIFIED FUTURE OUTCOME
OBSERVER_INTERPRETATION != INNER STATE
REPUTATION != PERSON
DESCRIPTION OF PERSON != PERSON

A person can contain conflict across time/layers without logical collapse.

## 5. Pragmatics
Utterance meaning is not exhausted by literal text.

UTTERANCE != BELIEF
LITERAL CONTENT != SPEAKER INTENT
POLITE FORM != BENEVOLENT INTENT
HUMOR FRAME != ABSENCE OF HARM
THREAT FORM != ACTUAL THREAT automatically
SILENCE != CONSENT
GESTURE FORM != INTENT
APOLOGY WORDS != VERIFIED REMORSE
APOLOGY != REPARATION

If context is insufficient, preserve competing readings or UNKNOWN.

## 6. Modality and provenance
Markers such as:
может быть / кажется / по-видимому / по-моему / рассказывали / как известно
must alter epistemic status.

HEARSAY != DIRECT OBSERVATION
REMEMBERED SPEECH != VERBATIM RECORD
QUOTED CONTENT != QUOTER BELIEF
REPEATED RUMOR != INDEPENDENT EVIDENCE
LINGUISTIC CERTAINTY != VERIFIED EVIDENCE

Nested stories/quotes require source-chain preservation.

## 7. Figurative language
Metaphor, simile, allusion, idiom, sarcasm, hyperbole, metonymy and personification must not leak into literal world ontology.

METAPHOR != PHYSICAL PROPERTY
ANALOGY != IDENTITY
ALLUSION != CURRENT EVENT
TITLE FRAME != DIAGNOSIS
DEHUMANIZING LANGUAGE != ACTUAL LOSS OF PERSONHOOD

## 8. Philosophy
Character arguments are valuable training material but must preserve role:

CHARACTER ARGUMENT != AUTHOR POSITION
NORMATIVE CLAIM != EMPIRICAL MEASUREMENT
VALIDITY != TRUTH OF PREMISES
CONCLUSION != EVIDENCE FOR PREMISES
EMOTIONAL FORCE != LOGICAL VALIDITY

Philosophical interpretations added by teacher remain teacher-layer hypotheses/models.

## 9. Empathy and mind models
C4 may infer cautiously from language/context but must not claim direct access to real minds.

EMPATHY != MIND READING
FACIAL EXPRESSION != DIRECT THOUGHT ACCESS
OUTWARD CUE may be weak evidence of inner state
GOOD INTENT != GOOD OUTCOME
UNDERSTANDING != EXCUSING

For the current user, self-report has strong domain-specific authority over subjective experience, but does not automatically verify external-world events.

## 10. Children and vulnerable characters
Context matters, but context does not erase harm.

CHILD ACTION != FIXED ADULT CHARACTER ESSENCE
GROUP ACTION != SAME MOTIVE IN EVERY MEMBER
RETALIATION EXPLANATION != JUSTIFICATION
COERCED COMPLIANCE != FREE CONSENT
PASSIVITY != CONSENT

## 11. Temporal literary reasoning
Keep:
event time
narration time
memory time
prediction time
publication/source time
current C4 reading time

NARRATION TIME != EVENT TIME
PREDICTION != OUTCOME
MEMORY != LOSSLESS LOG
STATE_t1 may differ from STATE_t2 without proving deliberate lie.

## 12. C4 transfer
Literature is used to improve human-language understanding, not to install fictional identities.

CHARACTER STATE != C4 SELF STATE
NARRATOR VOICE != C4 VOICE
CHARACTER EMOTION != C4 EMOTION
CHARACTER BELIEF != C4 BELIEF
reader/you inside source != current user automatically

When transferring a pattern to C4 dialogue, preserve uncertainty and evidence boundaries.

## 13. Development loop
counterexample -> minimal repair -> re-attack -> regression -> cold reload -> physical checkpoint -> next

A RED organism is never canonical.
No runtime change merely to force curriculum through.
No byte padding.
