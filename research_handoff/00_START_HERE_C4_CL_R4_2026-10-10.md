## Goal
Build a continuously existing-in-time, recursive, self-improving learner: world events, multiple clocks, durable experience, goals/unfinished thoughts, autonomous action selection, internally iterated hypotheses, revision of past beliefs, acquisition of transferable **computational operations**, efficient rest/wake, multimodal experience, and eventually natural Russian dialogue. A reply is ONE action, not the entire existence of the system. Stable source code can support lifelong learning: acquiring operations/weights != rewriting kernel.py. Cross-code-version migration is separate and currently unsupported.

C4 is NOT bound to graphs, transformers, DFP, WRAP, S, or W. Synthesize and ablate alternative structural / neural-weight / hybrid models; select based on evidence, safety, learning efficiency, transfer, entire training cost. Neural mechanisms may be embedded into one architecture rather than using an LLM as a separate interpreter. Transformer/vision-language model can be an external TEACHER, never implicit proof of truth.

## Four constitutional owners (not to be confused with epistemic invariants)
- EVAL — evaluation, source claims/hypotheses/uncertainty and checking predictions;
- COMMIT — authorized durable admission, status, retraction, provenance;

Historically five influence kinds MASK/VALUE/AVAIL/TRIGGER/STATUS; rough 4×4×5=80 typed relations. Mathematical intuition, not proven intelligence theorem.

Mandatory invariants: UNKNOWN != FALSE; REPORT != OBSERVATION; CLAIM != ADMITTED WORLD FACT; PREDICTION != EVIDENCE; INTERNAL REPLAY/SIM != INDEPENDENT SOURCE; ACTION REQUEST != VERIFIED RESULT; RECEIPT != CAUSAL PROOF; address != evidence; provenance != truth. ## Teacher protocol for local GPU-hosted LLM
1. Teacher != world: LLM gives candidate lessons/questions/hypotheses; independent simulator/world or verified intervention supplies ground truth FOR THAT ENVIRONMENT. Do not allow LLM to make up both lesson and confirming observation.
2. A multimodal LLM's image description is a sourced ASSERTION, not raw sensor OBSERVATION. Keep sensor payload/provenance separate; compare interpretations to independent checks.
3. S currently asks ~2–4 questions / 2,000 ticks. If using cheap local teacher, make query cost adjustable in DRIVE; measure GPU usage, experiment cost, false certification, question utility, and effect on transfer before proclaiming speedup.
No adapter implementing this teacher protocol was yet independently verified in CL-R4.
