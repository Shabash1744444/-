## Main research objective: acquire Russian from experience, not clone Qwen
Build a genuinely **learnable**, compact, persistent system that discovers segmentation, binding, compositional semantics, dialogue roles and time, can ask meaningful questions and can utter novel truthful phrases. Its results must persist when **Qwen teacher is turned OFF during heldout exam**. Teaching is not just `слово=сущность` mapping. Avoid hardcoded grammar for each Russian case, and avoid hidden LLM answer fallback.
Competitive candidates: (S) general typed sequence + variable binding + program synthesis on top of living S, (H) small trainable recurrent/SSM/CNN/auditory/visual encoders feeding structured learner, (N) matched-budget neural baseline; compare under frozen examiner, full cost. Graphs not mandatory; preferentially merge mechanisms rather than add ad-hoc organs. Missing generic capabilities: arbitrary-length sequences, lexical segmentation, open/unknown entity types, variable binders/speaker scope, temporal event/quote scope, learned audio-video alignments, compositional surface generation. Name primitives as computable inductive biases, **NOT preprogrammed Russian knowledge**; prove operation transfer into non-language domain.

## Three independent roles: teacher, world, examiner
Teacher on Windows PC: local **Qwen3-Omni-30B-A3B-Instruct**, via actual verified local runtime on AMD RX 7900 XTX 24GB/128GB RAM. Qwen officially supports text/audio/image/video input, Russian spoken IO. BUT quantized GGUF/llama.cpp/ROCm build might not expose all modalities: smoke-test actual endpoints first. Use text teaching initially if audio/video unsupported; local loopback adapter only, no paid cloud API required.
Teacher produces a structured *proposal*: Russian utterance, optional audio/image refs, candidate semantic program, contrastive example, predicted world consequence, uncertainty; always `TEACHER_CLAIM`, never `SENSOR` or `WORLD_TRUTH`. Qwen cannot see hidden examiner keys or generate its own confirming observations. The same foundation model cannot become independent witness by changing prompt.
World: independent deterministic Python/Unity/Godot simulator with action receipts/actual sensor data, randomized scene physics, IDs and image file hashes. Hidden truth only visible to evaluator, not C4 sensor input; learn grounded meanings via interventions/contrast.
Examiner: frozen independent holdouts and separate code path, never teacher-scored. For discourse claims without physical verification, use attributable speaker context, conversation feedback and appropriate uncertainty, NOT false physics 'truth'.

## Suggested learner architecture (to be tested)
1. Typed provenance journal: RAW_AUDIO/RAW_IMAGE/TEACHER_CLAIM/FEATURE/OBSERVATION/DERIVED/SELF_OUTPUT/REPLAY; clock_world/clock_dialogue/clock_narrated/clock_internal; source-identity, action receipt and witness roots.
2. Learnable sequence segmentation (graphemes/phonetic regions/visual tracks), alignment against actions/situations and contrastive counterexamples.
3. Learnable variable-role binding, deictic source frames and scope: e.g. `я` depends on speaker; quotes, nested beliefs, negation, narration and fictional world's time distinct from observed world.
4. Typed semantic program synthesis over learned primitives; induction of Russian inflection/agreement/order from contrasted pairs, not a fixed phrase dictionary. Manage combinatorial explosion with bounded search, learned templates/prior/beam plus sound falsification. Must be able to acquire a new *operator type*, not only recombine 2/4-domain truth tables.
5. DRIVE uncertainty/value-driven question/experiment selection, lower cost for cheap local Qwen but log token/time/world verification cost and guard source contamination; finite budget/sleep/no fake questions.
6. Optional small trainable acoustic/visual frontend with auditable representations and separate weights; pretrained Whisper/DINOv2 only explicitly labeled baseline/teacher. Captions/transcripts are fallible sourced annotations, not raw senses. TTS is a tool, not proof of voice skill.
7. Consolidation with auditably replayable witness roots, exceptions and versioned meanings; never discard hard counterexamples to compress.
